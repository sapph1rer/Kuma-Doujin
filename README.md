<h1 align="center">KumaDoujin</h1>

<p align="center">แอปอ่านมังงะ มังฮวา มังฮัว และโดจิน บน Windows รวมหลายเว็บไว้ในที่เดียว เขียนด้วย Rust</p>

---

## ความสามารถ

- **รวมหลายแหล่ง** ค้นหาและเลือกดูเรื่องจากทุกเว็บพร้อมกันในหน้าเดียว แหล่งไหนตอบก่อนก็แสดงก่อน ไม่ต้องรอแหล่งที่ช้า
- **แยกหมวดหมู่ชัดเจน** All / Manga / Manhwa / Manhua สำหรับเนื้อหาทั่วไป และ **Doujin 18+** แยกไว้ต่างหาก เนื้อหา 18+ จะไม่ปนกับหมวดอื่น
- **โหมด 18+** เปิดได้ใน Settings (ต้องยืนยันอายุ) ถ้าปิดไว้ แหล่ง 18+ และหมวด Doujin จะถูกซ่อนทั้งหมด
- **อ่านในแอป** มีแบบหน้าเดี่ยว สองหน้า และเลื่อนแนวตั้ง (เว็บตูน) ปรับได้ทั้งทิศทางอ่าน (ขวาไปซ้าย/ซ้ายไปขวา) การจัดหน้าพอดีกว้าง/สูง และซูม
- **เลื่อนอ่านตามใจ** ปรับความเร็วการเลื่อน, เลื่อนอัตโนมัติพร้อมปรับความเร็ว และระยะห่างระหว่างหน้า
- **ดาวน์โหลดไว้อ่านออฟไลน์** ดาวน์โหลดทีละตอนหรือทั้งเรื่อง มีแถบความคืบหน้า ถ้าดาวน์โหลดค้างกลางทาง ครั้งต่อไปจะต่อจากหน้าที่ค้างไว้ ดูและลบได้ที่หน้า Downloads
- **คลังส่วนตัว** อ่านต่อจากที่ค้างไว้ ประวัติการอ่าน บุ๊กมาร์ก และรายการโปรดแยกหมวด กำลังอ่าน / อ่านจบ / ไว้อ่านทีหลัง
- **เรื่องที่เพิ่งดูและประวัติค้นหา** เรื่องที่เปิดดูล่าสุดแสดงในหน้า Home และคำที่เคยค้นแสดงใต้ช่องค้นหา
- **ติ๊กตอนที่อ่านแล้ว** อ่านถึงหน้าสุดท้ายแล้วแอปติ๊กให้เอง หรือคลิกขวาที่ตอนเพื่อติ๊กอ่านแล้ว/ยังไม่อ่าน
- **อ่านตอนถัดไปต่อเนื่อง** ในโหมดแนวตั้ง เลื่อนเลยหน้าสุดท้ายแล้วจะเข้าตอนถัดไปเอง (ใช้กับเลื่อนอัตโนมัติได้)
- **โหมดถนอมสายตา** ลดความสว่างและโทนสีฟ้าของหน้า ปรับระดับได้ (ปุ่ม Night หรือกด N)
- **ซูมด้วยเมาส์** Ctrl + ล้อเมาส์ หรือดับเบิลคลิกเพื่อซูมตรงจุดที่กด
- **เรื่องเดียวกันจากหลายแหล่ง** หน้ารายละเอียดบอกว่าเรื่องนี้มีที่แหล่งไหนอีกบ้าง พร้อมจำนวนตอน ตอนล่าสุด และความเร็วของแต่ละแหล่ง
- **อัปเดตในแอป** เช็กเวอร์ชันใหม่จาก GitHub ตอนเปิดแอป แล้วดาวน์โหลด ตรวจ checksum และติดตั้งให้ใน Settings › Updates
- **รายงานปัญหา** Settings › Diagnostics มีปุ่มเปิดโฟลเดอร์ล็อก และคัดลอกสถานะ/error ของทุกแหล่ง
- **เร็ว** แคชผลค้นหา รายละเอียด รายชื่อตอน ปก และหน้าที่อ่านแล้ว

## ติดตั้ง

1. ดาวน์โหลด `KumaDoujin-vX.Y.Z-windows-x64.zip` จากหน้า [Releases](https://github.com/sapph1rer/Kuma-Doujin/releases)
2. แตกไฟล์ไว้ในโฟลเดอร์ไหนก็ได้
3. เปิด `kumadoujin.exe`

ต้องวาง `kuma-browser.exe` ไว้โฟลเดอร์เดียวกับ `kumadoujin.exe` และเครื่องต้องมี [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) ซึ่ง Windows 10/11 ส่วนใหญ่มีอยู่แล้ว

## ข้อมูลของแอปเก็บที่ไหน

ทุกอย่างเก็บไว้ในเครื่องที่ `%LOCALAPPDATA%\KumaDoujin` ได้แก่ ฐานข้อมูลประวัติ/บุ๊กมาร์ก แคชปกและหน้า (ล้างได้ใน Settings) และโฟลเดอร์ `downloads` ที่เก็บตอนที่ดาวน์โหลดไว้

ถ้าต้องการเปลี่ยนที่เก็บ ตั้งตัวแปรสภาพแวดล้อม `KUMADOUJIN_DATA_DIR`

## Build เอง

ต้องมี [Rust](https://rustup.rs/) รุ่น stable

```bash
git clone https://github.com/sapph1rer/Kuma-Doujin.git
cd Kuma-Doujin
cargo build --release
```

ไฟล์ที่ได้คือ `target/release/kumadoujin.exe` และ `target/release/kuma-browser.exe`

รันเทสต์:

```bash
cargo test
```

เทสต์ที่ต่อเว็บจริง (ต้องต่อเน็ต):

```bash
cargo test --test live_mangastream -- --ignored --nocapture
```

```bash
KUMA_BROWSER_EXE=target/debug/kuma-browser.exe cargo test --test live_gated -- --ignored --nocapture
```

## ออกเวอร์ชันใหม่

1. แก้ `version` ใน `Cargo.toml`
2. รัน `powershell -ExecutionPolicy Bypass -File scripts\make-release.ps1 -Notes "มีอะไรใหม่"`

สคริปต์จะ build แล้วทำ zip กับไฟล์ `.sha256` และสร้าง GitHub Release ให้ แอปที่ติดตั้งไว้จะเห็นเวอร์ชันใหม่ใน Settings › Updates

ทุกวัน GitHub Actions ([live-sources.yml](.github/workflows/live-sources.yml)) จะทดสอบทุกแหล่งกับเว็บจริง ถ้าแหล่งไหนพังจะเปิด issue ให้อัตโนมัติ

## ข้อควรรู้

- เนื้อหาทั้งหมดมาจากเว็บต้นทาง แอปไม่ได้เก็บหรือเผยแพร่เนื้อหาเอง และทุกหน้ามีลิงก์กลับไปที่เว็บต้นทาง
- เนื้อหา 18+ สำหรับผู้ที่มีอายุ 18 ปีขึ้นไป และอยู่ในพื้นที่ที่การเข้าถึงเนื้อหานั้นถูกกฎหมายเท่านั้น
- ถ้าเว็บต้นทางเปลี่ยนหน้าตาเว็บหรือเปลี่ยนระบบป้องกัน แหล่งนั้นอาจใช้งานไม่ได้ชั่วคราวจนกว่าจะอัปเดตแอป ดูสถานะของแต่ละแหล่งได้ที่หน้า Sources
